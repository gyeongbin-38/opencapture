# 캡처 보드 사용하기

홈에서 캡처하거나 라이브러리에서 이미지를 선택해 보드로 보냅니다. 여러 이미지를 한 작업 화면에 놓고 비교하며, 각 이미지는 이동하거나 모서리를 끌어 크기를 조절할 수 있습니다. 가로·세로·격자 정렬과 화면 맞춤을 사용하면 한 번에 정리할 수 있습니다.

이미지를 선택하면 아래에 필요한 작업만 표시됩니다. 도형과 메모는 도구를 열어 추가하고, 레이어 목록에서 순서·표시·잠금을 조절합니다. 보드를 여러 개 만들고 이름을 붙여 작업을 나눌 수 있습니다. 편집은 자동 저장되며 다음 실행에서 이어집니다.

보드의 선택 모드에서 이미지 위에 왼쪽 버튼을 약 0.65초 누르고 있으면 원형 진행 표시 후 배경을 제거합니다. 마우스를 끌거나 일찍 놓으면 실행하지 않습니다. 오른쪽 버튼을 함께 눌러도 취소합니다. 원본은 보존되며 실행 취소 또는 원본 복원으로 되돌릴 수 있습니다. 미리보기와 화면 위에 고정한 이미지에서도 같은 동작을 사용할 수 있습니다.

텍스트·메모·말풍선을 선택하고 속성의 내용 편집 버튼을 눌러 문구를 바꿉니다. 도형 속성에는 색상·선 두께·크기와 정렬이 모여 있습니다. 새 캡처가 추가되는 동안에도 현재 보드의 편집은 유지됩니다.

`Ctrl+K`로 명령을 검색하고, `Ctrl+Z`로 실행 취소, `Ctrl+Shift+Z`로 다시 실행, `Ctrl+0`으로 보드 내용을 화면에 맞춥니다. 도구의 추가 옵션은 해당 항목을 선택하거나 메뉴를 열었을 때 표시됩니다.

보드 결과는 PNG·PDF로 내보내거나, 이미지와 편집 정보를 함께 담은 `.ocboard` 파일로 저장해 다시 가져올 수 있습니다. 여러 원본 이미지의 복사와 레퍼런스 비교는 기존 라이브러리·비교 화면에서도 사용할 수 있습니다.
