# OpenCapture Quick — 가벼운 Windows 캡처

`OpenCaptureQuick.exe`를 실행하면 창 없이 트레이에서 대기합니다. 기본 영역 캡처는 Electron 편집기를 실행하지 않습니다. Windows의 .NET Framework를 사용하며 별도 npm/Python 설치는 필요하지 않습니다.

- **Ctrl+Shift+A**: 영역 선택 → 마우스를 놓으면 PNG 저장. Esc로 취소합니다.
- **Ctrl+Shift+Space**: 전체 편집기 열기/닫기. 전체 버전의 `OpenCapture.exe`를 같은 폴더에 두어야 합니다.
- 다른 앱이 기본 키를 사용 중이면 Ctrl+Alt+A / Ctrl+Alt+Space를 시도합니다. 실제 등록된 키는 트레이 메뉴에 표시됩니다. 기존 앱의 키를 해제하거나 빼앗지 않습니다.
- 트레이에서 마지막 캡처나 저장 폴더를 열 수 있습니다. 종료도 트레이 메뉴에서 합니다.

기본 저장 위치는 `사진/OpenCapture`입니다. 이미 전체 편집기에서 컬렉션을 지정했다면 그 위치를 사용합니다. 여러 장을 각각 고유한 이름으로 저장하며 원본 파일을 덮어쓰지 않습니다.

이 작은 배포본은 **영역 캡처·저장 전용**입니다. 주석 편집, 녹화, OCR, 번역, 자동 누끼, 자동 복사·고정 등은 전체 편집기를 같은 폴더에 둔 전체 배포본에서 사용하세요. 원본 저장은 먼저 끝나며, 선택한 자동 작업이 있을 때만 편집기를 실행합니다. 저장 후 목록 등록이 실패하더라도 원본 경로를 안내합니다.

화면 접근이 불가능하거나 전체 프레임이 검은색이면 저장 성공으로 가장하지 않고 오류를 표시합니다. 실제 사용자 화면의 DPI/다중 모니터/드래그 조작은 추가 검증 중입니다. 캡처 합성 테스트와 단축키 등록 충돌 테스트를 통과했지만, 모든 PC에서 충돌이 없거나 같은 속도가 나오는 것을 보장하지 않습니다.

소스는 `native/`와 `scripts/build-quicklaunch.ps1`, 라이선스는 `LICENSE`에 있습니다. GPL-3.0으로 무료 배포합니다. 빌드: Windows PowerShell에서 `./scripts/build-quicklaunch.ps1` 실행.
