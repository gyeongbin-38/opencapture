# 웹 실험실 점검 기록

## 수정한 원인

| 문제 | 수정 |
|---|---|
| 작은 핀에서 툴박스도 작아짐 | 이미지 너비에 따른 툴바 줌 제거 |
| 확장 툴박스가 이미지와 겹침 | 고정 ±36px 대신 실제 툴바 크기와 captureDock 사용 |
| 화면 가장자리에서 툴바 잘림 | 핀·툴바 관찰, 이동·리사이즈마다 화면 내부 배치 |
| 좁은 캡처 화면에서 즐겨찾기 넘침 | 실측 여유 폭으로 버튼을 분할하고 나머지를 더보기로 이동 |
| 숫자 필드 의미와 간격이 불명확 | X/Y/너비/높이/선/글자 라벨 및 그룹·40px 조작 영역 |
| 샘플 위에 빈 보드 안내가 표시됨 | 공유 컴포넌트의 hidden 속성 우선 적용 |
| 첫 샘플 배치가 화면보다 큼 | 보드 표시 후 첫 데이터 격자 배치·화면 맞춤 |
| 샘플 문구가 그림에 덮임 | 각 Canvas 경로에서 beginPath 적용 |
| 실행 취소가 두 번 적용될 수 있음 | 셸의 중복 Ctrl+Z 처리 제거, 공유 보드 핸들러 사용 |
| 보관함 누끼가 이전 보드 선택에 적용될 수 있음 | 활성 화면의 선택만 사용 |
| 텍스트 번역이 이미지 선택을 요구함 | 번역 진입을 이미지 작업의 선택 조건에서 분리 |
| 다중 복사 설명과 결과가 다름 | 실제 격자 합성, 출력 픽셀 상한과 순차 디코딩 |
| 가림 처리가 모든 OCR 줄에 적용됨 | 공통 민감정보 패턴에 맞는 줄만 가림 |
| 잘못된 보드 추가가 고아 에셋을 남길 수 있음 | 전체 문서 검증·용량 확인 뒤 원자적 쓰기 |

## 증거

- `npm test -- --maxWorkers=2`: 25개 테스트 파일, 121개 테스트 통과. 기본 병렬 실행의 워커 시작 제한 시간 문제는 병렬도를 제한해 재검증했습니다.
- `npm run web:check`, `npm run web:build`, `npm run typecheck`, `npm run lint`: 통과.
- `.evidence/web-lab/qa.json`: 격리된 Electron 웹 렌더러에서 7개 흐름 묶음 통과, renderer/main 오류 0개. 도형·속성·단일 undo/redo, 검색·다중 선택·4종 비교, 참고창 크기/이동/잠금, 180×120 자르기, 반응형 배치, 실제 PNG/PDF/OCBOARD/GIF 내보내기를 확인했습니다.
- 390px에서 참고창이 기존 데스크톱 너비를 유지해 닫기 버튼이 잘리는 문제를 수정했습니다. 창 크기와 위치를 화면 안에 맞추며 이미지 비율을 유지합니다.
- 캡처·미디어 모듈의 어두운 글자 폴백을 공통 다크 테마 토큰으로 연결했습니다.
- 격리 렌더러의 이미지·합성 클립보드 쓰기는 권한 때문에 수동 확인 대상으로 남겼습니다. 화면 공유/녹화 권한과 실제 영상 트림도 별도 사용자 브라우저 확인이 필요합니다.

- `.evidence/web-lab/browser-checks.json`: 실제 Chrome에서 자동 기본 점검 실행 후 내려받은 결과. 14개 통과, 0개 실패, 3개 직접 확인.
- `.omx/plans/test-spec-web-lab.md`: 화면/저장/처리/권한 점검 범위.
- 브라우저 검사 중 발생한 `Debugger unattached`는 검사 연결 손실로 기록했습니다. 앱 무한 루프로 단정하지 않았습니다.

데스크톱 전용 동작과 화면 공유 권한 선택은 별도 앱/사용자 확인 대상입니다. 공통 소스는 수정했지만 이번 작업의 배포 대상은 로컬 웹 실험실입니다.
