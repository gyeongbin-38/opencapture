# OpenCapture 기능 실험실

로컬 웹사이트에서 캡처·편집·비교 흐름을 개발하고 버튼별 동작과 화면 배치를 확인합니다.

```powershell
npm run web:dev
```

주소: <http://127.0.0.1:5187/>. 브라우저의 IndexedDB에 작업을 저장합니다. 데스크톱 앱의 보관함과는 별도이며, `?session=이름`을 붙이면 독립된 테스트 작업 공간을 사용할 수 있습니다.

## 사용할 수 있는 화면

- **보드**: 여러 이미지 배치·크기·정렬·그룹, 도형·메모·레이어, 실행 취소, PNG/PDF/편집 파일 내보내기
- **캡처**: 샘플 영역·창·긴 페이지, 실제 브라우저 화면 선택, 비율·크기·이전 영역·타이머, 아래 툴바와 우클릭 원형 도구
- **보관함**: 가져오기·붙여넣기·검색·다중 선택, 격자 합성 복사, 자르기·회전·크기 변경, OCR·누끼·업스케일·가림·번역
- **참고창**: 이 웹페이지 위에 여러 이미지 표시. `위치 잠금`은 별도로 이동·리사이즈·휠을 잠급니다. 툴바는 이미지와 독립된 크기로 화면 안에 배치합니다.
- **비교**: 나란히·분할·교대 표시·픽셀 차이, 비교 메모와 결과 내보내기
- **미디어**: GIF 프레임/FPS/구간, 동영상 프레임 추출·구간 재녹화, 화면 녹화
- **기능**: 기능 목록, 직접 확인 체크, 버그 기록/JSON 내보내기, 격리 데이터로 자동 기본 점검

실제 화면 공유·녹화는 브라우저 권한 선택이 필요합니다. 전역 단축키, 마우스 콤보, 다른 앱 위에 항상 표시, OS 파일 묶음 클립보드는 기능 목록의 **앱 연동** 항목에서 구분합니다. 웹 참고창을 OS의 항상 위 창으로 표시하지 않습니다.

누끼·OCR·AI 확대·번역·가림은 localhost 처리 서비스가 기존 로컬 모델을 실행합니다. 이미지가 외부 AI 서비스로 업로드되지 않습니다. AI 확대 모델이 없으면 첫 사용 시 기존 검증된 모델을 다운로드합니다.

## 검증과 개발

```powershell
npm run web:check
npm run web:build
# 개발 서버가 실행 중인 별도 터미널에서:
npm run web:test
```

기능 화면의 **자동점검 실행**은 별도의 테스트 DB와 생성 이미지를 사용합니다. 저장/리비전 충돌/자산 보존/이미지 변환/도구 배치/길게 누르기를 확인하며, 선택하면 실제 모델도 호출합니다. 테스트 DB는 연결을 닫은 뒤 정리합니다. 이 결과는 화면의 모든 버튼을 눌렀다는 뜻이 아니며 권한과 화면 조작은 별도로 표시합니다.

`web-dist`는 클라이언트 빌드입니다. 로컬 모델 기능까지 시험하려면 `web:dev`의 localhost 서비스가 함께 실행되어야 합니다.

## 앱 통합 경계

공통 보드·도형·비교·길게 누르기·툴바 배치 코드는 앱과 같은 모듈을 사용합니다. 웹은 `web/boardApi.ts`의 IndexedDB 구현을 주입하고, 앱은 기존 IPC/파일 저장소를 사용합니다. 웹에서 확인한 공통 수정은 다음 앱 빌드에 반영할 수 있습니다.
